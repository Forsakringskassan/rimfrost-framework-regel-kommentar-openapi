# rimfrost-framework-regel-uppgiftskommentar-openapi

OpenAPI definition for registering uppgiftskommentar in kommunicering regel endpoints.
Contains endpoints that are identical regardless of the rule implementation.

## Artifacts

- Maven artifact: <https://github.com/Forsakringskassan/repository>

## Modules

- `rimfrost-framework-regel-uppgiftskommentar-openapi-spec` — OpenAPI YAML spec artifact
- `rimfrost-framework-regel-uppgiftskommentar-openapi-jaxrs-spec` — Generated JAX-RS server stubs
